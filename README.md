# You+3 by GOLF+ (concept demo)

A gamified "build your dream foursome" web experience. Allocate a budget across five golf-lifestyle categories, answer ten quick questions, and the game assembles your perfect celebrity foursome, capped with an AI-generated recap of how the round went.

## How it works

1. **Budget phase.** You get 13 points to spend across five categories (instructor, clothes, course, transport, clubs), each priced 1 to 4, with a couple of expensive legend unlocks. Max spend is 20, so every build is a tradeoff, and every tradeoff is a confession.
2. **Questionnaire.** Ten quick questions map to the same attribute axes as the celebrity roster.
3. **Matching.** Your vector is scored against a 50-name celebrity matrix with curation rules (no all-president foursomes, one loudmouth per group, a politics gate, and one special crash-the-party card).
4. **The recap.** A short, personalized story of how your round went. This is the screenshot moment.

## Tech notes

- Single-file HTML/JS, mobile-first, no backend, no accounts, no tracking.
- Deterministic scoring against a static attribute matrix.
- Built solo, quickly, with AI as the force multiplier.

## The point

This is a concept demo of a reskinnable engine, not a one-off. Swap the roster, swap the budget categories, and the same mechanic becomes a shareable acquisition tool that captures preference data through play.
